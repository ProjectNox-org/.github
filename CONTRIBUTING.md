# Como contribuir

Obrigado por contribuir com o Project Nox.

## Solicitações e problemas

Antes de abrir uma solicitação, pesquise as issues existentes. Para problemas ou pedidos de extensões, use a [Central de solicitações](https://github.com/Awerkori/project-nox-requests) e forneça detalhes que ajudem a entender e reproduzir o caso.

## Alterações de código e documentação

1. Leia o README e as instruções específicas do repositório envolvido.
2. Descreva o problema ou a proposta com clareza e mantenha cada contribuição focada.
3. Execute as verificações indicadas pelo projeto e descreva os testes realizados no pull request.
4. Não inclua credenciais, dados pessoais ou conteúdo de terceiros sem autorização.

Mantenha uma comunicação respeitosa e siga as orientações publicadas em cada projeto.
